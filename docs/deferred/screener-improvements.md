# スクリーナーの改善項目（先送り）

2026-11-22 の品質チェックで挙がった項目のうち、まだ対応していないもの。不具合5件の修正を優先し、変更範囲を小さく保つために分けた。

| 優先 | 項目 | 今やらない理由 | 再開条件 |
|---|---|---|---|
| 1 | キャッシュにフィルタ前の生データを保存する（今はフィルタ後の結果を保存しているため、閾値を変えても最大1時間は古い結果が返る） | 不具合5件の修正とは独立していて、キャッシュ構造の変更になる | 次の改修時。または閾値を変えるとき |
| 2 | ティッカーのソートを `localeCompare` に変える（`Number('130A')` が NaN になり順序が不定） | 表示順だけの問題で、抽出結果は正しい | 英字付きコードが結果に出たとき、または1番と同時に |
| 3 | HTTP エラー時のリトライと通知（500が1回出ると、その業種の残りページが通知なしで欠落する） | エラー時はキャッシュしないため、再実行すれば回復する | 欠落が実際に起きたとき |
| 4 | 6分の実行時間制限への対策（中断・再開の仕組み） | 実際のリクエスト数は約230〜270件と見込まれ（推測）、キャッシュがあれば制限に届かない | 実行時間超過のエラーが出たとき |
| 5 | エラーで終了したときに `closeProgress()` が呼ばれない／`sheet.clear()` で消す対象のシートを固定する／未使用コード（`CACHE_INDUSTRY_DURATION`、`CACHE_CLEAR_MAX_INDUSTRY`、`useCache` 引数、`Parser` ライブラリ）の削除 | 実害が小さい | 上記の改修時についでに |

## 対応しないもの

- **型の統一**: `setValues` で渡した数字風の文字列はシート側で数値に変換されるため、実害がない
- **oauthScopes の明示**: スコープの自動推論は標準の動作で、書き漏らすと動かなくなるリスクの方が大きい。再開条件は、権限を絞る必要が出たとき
