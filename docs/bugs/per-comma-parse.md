# PER 1,000倍以上が1〜9倍として読まれる

## 症状

`pickup` の先頭に、共和レザー（3553）が PER 1倍・ミックス係数 0.55 で出た。予想配当性向は 6500%、減益予想は -97% で、割安には見えない（2026-11-22）。

## 原因

株探の業種一覧の PER は今期予想ベースで、共和レザーは「1,052.5倍」と表示されている。`get_stock_data` は「倍」だけを取り除いて `parseFloat` していたため、最初のカンマで読み取りが止まり、PER が 1 になっていた。

- 予想利益がほぼゼロの銘柄ほど PER が4桁になる。そのため、最も割安でない銘柄が最も割安として先頭に来る、逆向きの不具合だった
- 2026-11-22 の結果では、予想配当性向 ÷ 配当利回りで逆算した予想 PER が1,000倍以上のものが3件あった（3553 共和レザー、274A ガーデン、8185 チヨダ）

## 対処

PER・PBR・配当利回りは、カンマを取り除いてから数値にする。テスト「PER 1,000倍以上でもカンマで切れずに読み…」を追加した。

修正を push した後の実行でも、3件は PER 1倍のまま残った。業種一覧のキャッシュには、元のページではなく読み取り済みの値（PER=1）が入っていたため（1時間有効）。キャッシュ種別を `stocks` から `stocks_v2`（定数 `STOCKS_CACHE_TYPE`）に変え、古いキャッシュを使わないようにした。

## 再発防止・注意

- 業種一覧の読み取り方（`get_stock_data`）を変えたら、`STOCKS_CACHE_TYPE` の番号を上げる。上げないと最大1時間、古い読み取り結果で判定される

- 株探の数値は桁区切りカンマ付きで出る。`parseFloat` / `Number` の前に必ずカンマを消す
- 一時的な利益で PER が低く出る銘柄を下げる「予想 EPS で PER を再計算する」案は不要と判断した。株探の一覧 PER がすでに予想ベースのため
