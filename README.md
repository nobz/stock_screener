# invest-tool（銘柄スクリーニング）

「今の稼ぐ力はあるのに割安」な銘柄の候補を、Google スプレッドシート上で絞り込むための Google Apps Script 製ツール。株探（kabutan.jp）をスクレイピングし、割安・高配当・予算内・流動性の条件で候補を抽出して `pickup` シートに並べる。

## 使い方

1. 対象のスプレッドシートを開く（スクリプトは clasp でデプロイ済みのものが動く）
2. メニュー「株価取得」→「settingsシートを開く」で `settings` シートを確認する。C列の値を変えると次回更新から反映される
3. メニュー「株価取得」→「銘柄データ更新」を実行する。結果は `pickup` シートに出力される（割安な順＝ミックス係数の小さい順）
4. 銘柄名をクリックすると Yahoo!ファイナンスの銘柄ページが開く
5. settings の値だけを変えて試したいときは「キャッシュで再判定（取得しない）」を使う。ネット取得を一切せず、キャッシュ済みの生データに新しい閾値だけを適用して `pickup` を作り直すため速い

補足:

- 「キャッシュで再判定」はキャッシュが残っている間（最大1時間）だけ使える。データが無ければその旨を表示するので、その場合は通常の「銘柄データ更新」を先に実行する。一部ページだけキャッシュ切れの場合は結果が欠ける可能性があり、ログに注意が出る
- 判定ロジックや閾値を変えた直後は、メニュー「キャッシュクリア」を実行してから更新する（業種ページのキャッシュが最大1時間残るため。settings の変更だけなら生データキャッシュ方式なのでクリア不要）
- GAS の実行時間制限（6分）があるため、進捗はトースト通知で表示される

## 判定条件

| 段階 | 条件 | 既定値 | 備考 |
|---|---|---|---|
| 第1段階 | グレアム・ミックス係数（PER×PBR）が上限未満 | 11 | PER/PBR が欠損している銘柄は判定不能として除外 |
| 第1段階 | 配当利回りが下限以上 | 3.5% | |
| 第1段階 | 株価×単元株数が予算上限以下 | 300,000円（=株価3,000円以下） | 値がさ株の除外が目的 |
| 第1.5段階 | 直近25営業日の平均出来高が下限超 | 10,000株 | 候補だけ時系列ページを追加取得。取得失敗・日数不足は「不明」として落とさない |
| 第2段階 | ROE・営業利益率・自己資本比率・配当性向など | 未実装 | 設計は [docs/deferred/stage2-quality-screening.md](docs/deferred/stage2-quality-screening.md) |

## settings シート

C列の値だけを編集する。キーが不足している場合は実行時に自動で末尾へ追加され、既存の値は上書きされない。

| キー | 設定名 | 初期値 |
|---|---|---|
| `maxBudgetPerStock` | 1銘柄の予算上限（円） | 300000 |
| `unitShares` | 単元株数 | 100 |
| `grahamMixThreshold` | グレアム・ミックス係数の上限 | 11 |
| `dividendYieldThreshold` | 配当利回りの下限（％） | 3.5 |
| `minAverageVolume` | 25日平均出来高の下限（株） | 10000 |
| `minRoe` ほか4項目 | 【第2段階・予約】 | 未適用 |

## 技術スタック

| 領域 | 採用 |
|---|---|
| 実行環境 | Google Apps Script（V8 ランタイム） |
| データ取得 | 株探のスクレイピング（`UrlFetchApp`＋正規表現パース）。業種一覧 `s.kabutan.jp/sectors/`、時系列 `kabutan.jp/stock/kabuka` |
| キャッシュ | `CacheService`（業種ページの生データ1時間、出来高は銘柄単位1時間） |
| デプロイ | clasp（`clasp push --force`）。送信ファイルは `.claspignore` で限定 |
| テスト | Node.js 標準テストランナー（`node --test`）。GAS のグローバルをモックして `.gs` をそのまま読み込む |

ファイル構成:

| ファイル | 役割 |
|---|---|
| `stock_screener.gs` | 本体。設定読み込み、スクリーニング、シート出力 |
| `finance.gs` | 株探から株価を取得するユーティリティ |
| `tests/quality_fixes.test.js` | 回帰テスト |
| `appsscript.json` | GAS マニフェスト |
| `docs/` | 不具合記録・先送り仕様・作業日誌（索引は [docs/README.md](docs/README.md)） |

## 開発手順

```powershell
# テスト
node --test tests/quality_fixes.test.js

# デプロイ前に送られるファイルを確認する
clasp show-file-status

# デプロイ
clasp push --force
```

- `.gs` ファイルを増やしたら `.claspignore` にも追記すること。テストファイルが GAS に送られるとスクリプト全体が読み込みエラーになる。詳細は [docs/notes/clasp-push.md](docs/notes/clasp-push.md)
- パース処理を変えるときは、実ページの HTML を取得して構造を確認してから直すこと（株探の HTML は予告なく変わる）

## 制約・注意

- 株探は非公式なスクレイピングであり、HTML 構造の変更で突然動かなくなる可能性がある
- GAS の実行時間は6分まで。全銘柄ではなく候補に絞ってから個別ページを取得する設計はこのため
- 出来高のキャッシュは「キャッシュクリア」の対象外（GAS ではキャッシュキーを列挙できないため）。実害は最大1時間古い出来高で判定すること
- このツールは候補の抽出までを行い、売買の判断や注文は行わない
