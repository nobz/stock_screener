# Git コミットメッセージは日本語で記述する

CRITICAL: All Git commit messages MUST be written in Japanese.

## ルール

- Git コミットメッセージは必ず日本語で書くこと
- 英語は一切使用しないこと
- 変更内容を簡潔に日本語で説明すること

## 例

良い例:
- "銘柄データ取得機能を追加"
- "キャッシュ機能を実装して高速化"
- "バグ修正: データ構造の問題を解決"
- "Yahoo!ファイナンスへのリンクを追加"

悪い例:
- "Add stock data fetching feature" (英語なのでNG)
- "Implement cache" (英語なのでNG)
